# 담터 별빛캠핑장 ★ 3D 둘러보기

경기 포천시 관인면 담터길 307-2 **담터 별빛캠핑장**을 캠핑장 배치도(대피안내도), 위성사진, 직접 찍은 사진·영상을 바탕으로 3D로 재구성한 웹페이지입니다. 브라우저에서 바로 실행되며 설치가 필요 없습니다.

## 기능
- **두 가지 모드**: 시작 화면에서 **둘러보기**(실제 캠핑장 분위기 그대로, 다른 손님들의 텐트·차·사람이 있는 상태) 또는 **체험하기**(비어 있는 캠핑장에서 직접 캠핑) 선택
- **체험하기 (캠핑 시뮬레이션)**
  - 다른 손님의 텐트·차·사람 없이 시작하고, 내 차를 몰고 진입로로 들어옵니다. 차는 자유롭게 운전하고(W/S 가속·후진, A/D 방향, Space 브레이크) 아무 데나 세워 내렸다가(E) 다시 탈 수 있으며, 밤엔 전조등이 켜집니다
  - **매점 앞 캠장님**(사진 속 모습: 남색 캡, 청록 티셔츠, 검은 러닝 조끼, 흰 팔토시, 검은 반바지, 흰 양말)께 체크인하고 **쓰레기 봉지**를 받아야 캠핑 기능이 열립니다
  - **텐트 치기·철수**: A·B·별빛존 사이트에서 터널형·에어·벨·티피·돔·캐빈 텐트 중 골라 피칭하면 타프·테이블·의자까지 단계별로 설치됩니다. 계곡 쪽 사이트는 텐트 입구와 의자가 계곡을 향하고, 빨간 벽돌은 화로 자리로 비워 둡니다
  - **모닥불**: 빨간 벽돌 위에 화로를 놓고 장작에 불을 붙이고(불꽃·불티·연기·타닥 소리·주변 조명), 물을 부어 끕니다
  - **고기 굽기**: 모닥불을 피운 화로의 석쇠에 삼겹살·목살·소시지·새송이·잡은 물고기를 올려 면마다 익는 정도를 보고 뒤집고 집습니다(완벽/덜 익음/탐 판정, 지글 소리·연기)
  - **계곡 고기잡이**: 찌낚시(힘 조절 던지기 → 입질에 챔질 → 줄 장력을 지키며 릴 감기)와 족대질(어망 놓기 → 돌 밟아 몰면 물고기 그림자가 족대로 몰려듦 → 들어 올리면 족대 안에서 파닥이는 물고기를 가까이서 확인). 피라미·갈겨니·버들치·쉬리·꺽지·동사리·메기·다슬기가 잡히고 아이스박스에 담겨 구워 먹을 수 있어요 (겨울엔 계곡이 얼어 불가)
  - **우리 가족 캐릭터**: 시작 화면에서 주인공을 고를 수 있어요 — 30대 여성(갈색 단발·선글라스·분홍 티셔츠·베이지 반바지, 기본) 또는 30대 남성(짧은 머리·캐주얼 재킷·청바지). 텐트를 치면 10대 딸 **아윤**(하늘색 줄무늬 셔츠·도트 캐미솔·청반바지·포니테일)과 **하윤**(하늘색 니트 가디건·흰 반바지·묶은 머리)이 테이블 의자에 앉아 있어요
  - **튜브 물놀이**: 계곡에서 줄무늬 튜브에 앉아 이동키로 저어 다니고, 물살을 따라 천천히 떠내려가요
  - **밤 별 관측**: 체험 중에도 밤이면 망원경 앞에서 달·토성을 볼 수 있어요
  - **할리갈리**: 테이블 의자에 앉으면 딸 아윤·하윤과 3인 할리갈리가 테이블 위에서 진행됩니다. 56장(과일별 1×5·2×3·3×3·4×2·5×1), 차례로 뒤집다 같은 과일이 정확히 5개면 종을 먼저 친 사람이 바닥 카드를 모두 가져가고, 잘못 치면 한 장씩 벌칙. 친구들은 사람처럼 들쭉날쭉한 반응 속도로 종을 치고 가끔 헛손질도 해요
  - **체크아웃**: 활동하며 쌓인 쓰레기(캔·페트병·트레이·과자 봉지·종이컵·휴지 등)를 **분리수거장**에서 캔·병 / 플라스틱·비닐 / 종이 / 일반쓰레기로 모두 분리해야 체험을 마칠 수 있고, 마지막에 체험 요약이 나옵니다
- 메뉴 맨 아래 **메뉴 닫기**·**앱 종료** 버튼 (안드로이드 앱에서는 두 번 눌러 바로 종료, 웹에서는 탭을 닫으라고 안내)
- 캐릭터를 움직이며 **1인칭 / 3인칭 / 항공** 시점으로 둘러보기
- **봄 / 여름 / 가을 / 겨울** 계절 전환 — 진달래·산벚과 꽃잎, 짙은 녹음과 반딧불이, 단풍과 낙엽, 눈 덮인 땅·언 계곡·눈 내림
- **낮 / 노을 / 별밤** 시간 전환 (계절별 해 높이·해 지는 시각 반영, 별밤에는 은하수와 볼라드등·줄전구·모닥불 점등)
- 캠핑장 배치도 그대로: 진입로 다리 → 멀티존·A1–A5 → 피크닉존 → B1–B15 (계곡 쪽), 별빛존 1–6·관리동/매점·화장실·샤워실·개수대·분리수거장·C1–C2·주차장·흡연구역 (산 쪽)
- 바닥 **대피로** 화살표 표시, 배치도와 같은 방향의 미니맵(클릭 이동), 바로가기, 계곡·모닥불·풀벌레·매미 소리
- **담터계곡 재현**(현장 영상 기준): 자갈 바닥이 비치는 맑고 얕은 물, 화강암 사석을 쌓은 호안, 자갈 모래톱, 돌보와 흰 물살, 물가 반영
- **여름 계곡 래프팅**: 물 흐름 방향(B존 쪽)으로 셋이 박자를 맞춰 노를 저으며(캐치 → 당기기 → 회수) 빠르게 내려가고, 노에서 튀는 물보라, 뱃머리에서 V자로 퍼져 나가는 항적 물결과 선미 뒤 거품, 노가 물에 들어간 자리의 동심원 물결, 파도에 맞춰 흔들리는 보트. 끝에서 내려 보트를 머리 위로 들고 돌계단과 통로를 따라 피크닉존 쪽으로 다시 올라가 띄우기를 반복 (메뉴의 '여름 래프팅' 버튼으로 바로 이동)
- **마스코트 고양이 ‘봄이’**: 은빛 태비 무늬의 스코티시폴드(앞으로 접힌 귀·크고 둥근 눈·분홍 코와 젤리). 얼굴은 봄이 사진을 바탕으로 만든 얼굴 텍스처를 SDF로 빚은 동그란 머리에 투영하고, 그 위에 반짝이는 3D 눈(동공 크기 변화)·코·여닫히는 입·수염을 얹었습니다. 눈 깜빡임, 천천히 눈 감기(◡◡ 미소 눈), 고개 갸웃, 귀 씰룩, ‘냥~’ 하고 우는 입 모양과 말풍선(소리 켜기 시 울음소리), 사냥할 때 커지는 동공, 문 앞 낮잠의 감은 눈까지 표정이 바뀝니다. 관리동 앞을 어슬렁거리다 나비가 오면 살금살금 다가가 엉덩이를 씰룩이고 폴짝 덮치며, 밤과 겨울에는 매점 문 앞 인조잔디에서 낮잠을 잡니다. **C 키**나 봄이를 클릭(탭)하면, 또는 바로가기 ‘고양이 봄이’로 얼굴을 가까이 보는 봄이 카메라로 바뀝니다 (드래그로 돌려 보기, 휠로 거리, 이동키로 복귀)
- **별 관측 망원경 (밤)**: 밤이 되면 관리동과 C사이트 사이 인조잔디 옆에 셀레스트론 넥스타 90GT(구경 90mm·초점거리 910mm·f/10 굴절) 망원경이 세워집니다. 쌍레일 알루미늄 삼각대와 다리 고정 레버, 아이피스 구멍이 난 액세서리 트레이(쓰지 않는 아이피스가 꽂혀 있음), 구리색 링이 있는 외팔 고투 경위대, 빨간 도브테일과 유광 경통, 후드 속 멀티코팅 대물렌즈, 랙앤피니언 초점부와 천정 프리즘, 5x24 파인더, 빨간 버튼이 빛나는 핸드 컨트롤러와 꼬인 코드, 빨간 LED 표시창의 12V 전원 박스와 빨간 케이블, 인조잔디 매트와 LED 랜턴까지 사진대로 만들었고, 대상을 고르면 실제로 달·토성 방향으로 고투 회전합니다. 가까이 가서 망원경을 클릭(탭)하거나 **E 키**(바로가기 ‘별빛 망원경’)를 누르면 아이피스 시야로 바뀌어 **달**과 **토성**을 볼 수 있고, 아이피스 **20mm(46배) · 14mm(65배) · 9mm(101배)**로 배율과 실시야(1.10° · 0.77° · 0.49°)가 바뀝니다. 초점 조절, 드래그·방향키 미동, 다시 겨누기 지원. 밤하늘에도 달(사진 텍스처·달무리)과 토성(노란 점)이 떠 있습니다
- **계곡 물결**: 하류로 밀려가는 잔물결과 보 아래 여울의 높은 파도·흰 물살
- **관리동 재현**: 흰 가로 사이딩, 원형 로고가 걸린 가운데 박공동과 양쪽 경사지붕 날개동(화장실·샤워실), 유리문·통창, 벽등, 인조잔디 화단과 화분, 다듬은 소나무와 돌 화단·태양광 정원등, 줄전구, 파라솔 테이블, 홍단풍, 나무 그네 퍼걸러
- 관리동 앞 **숯불 바비큐**: 바퀴 달린 그릴(뚜껑·온도계·사이드 선반·고기·연기)과 고기를 굽고 먹는 세 사람
- **별빛존은 텐트 전용**(벨텐트·터널·티피·돔+헥사타프·에어텐트), 바로 앞 주차장은 별빛존 쪽으로 **후면주차**, 고무 휠스톱 설치
- 고급 텐트 모델: 폴 슬리브·에어빔, 메시 창과 말아 올린 스톰플랩, 원단 주름, 스커트, 가이라인·팩, 캔버스 캐빈텐트(굴뚝 포함)
- 대형 럭셔리 SUV·준대형/대형 세단·중형 SUV·미니밴·소형 SUV 급의 차량: 실제 차급 치수 기반 차체, 유리·필러·크롬 몰딩, 그릴·랩어라운드 램프, 멀티스포크 휠·브레이크, 번호판 (특정 제조사 디자인·엠블럼은 넣지 않음)
- PC(키보드·마우스)와 모바일(가상 조이스틱) 모두 지원

## 렌더링 기술 (직접 작성한 GLSL 셰이더)
외부 렌더링 라이브러리 없이 three.js 기본 재질에 `onBeforeCompile`로 GLSL을 끼워 넣고, 후처리 파이프라인도 직접 작성했습니다. 메뉴의 **그래픽: 고급 / 표준 / 가볍게**로 단계를 고를 수 있고, 프레임이 계속 떨어지면 자동으로 한 단계 낮춥니다.

| 대상 | 구현 방식 |
|---|---|
| 화면 전체 (후처리) | 장면을 MSAA 4x 반정밀도(Half Float) 렌더 타깃에 깊이 텍스처와 함께 한 번 그린 뒤 ① 깊이 버퍼로 법선을 복원하는 **화면공간 앰비언트 오클루전(SSAO, Alchemy/SAO 방식, 14샘플 + 깊이 인식 양방향 블러)** ② 높이에 따라 옅어지는 **대기 원근(높이 안개 적분 + 태양 쪽 산란광)** ③ **듀얼 카와세 블룸**(밤 조명·물 반짝임) ④ **ACES 톤매핑 + 필름 그레이딩**(채도·스플릿 토닝·S커브·비네팅·디더링) |
| 산 숲 (나무 3.8만 그루, 인스턴싱) | 3D 밸류 노이즈 fbm으로 **잎 뭉치 명암·범프 노멀**, 가장자리 알파를 **alpha-to-coverage**로 부드럽게 깎은 실루엣, 역광 **잎 투과광**, 나무마다 다른 바람 흔들림, 겨울엔 반투명한 잔가지 덩어리 |
| 가까운 나무 | 512px 잎 다발 텍스처(잔가지 + 잎맥·그라데이션 잎), 역광 투과광·군집별 색 변화·잎 떨림, 나무껍질은 세로로 늘인 3D 노이즈의 **골·판 범프와 이끼** |
| 사람 | 피부: 랩 라이팅 **피하 산란(SSS) 근사**·역광 귀/윤곽 투과·부드러운 림, 머리카락: **Kajiya-Kay 이방성 하이라이트 2겹** + 결 무늬 범프, 옷: 주름·섬유 노이즈 범프와 **벨벳 시언(sheen)** (3D 캐릭터 모델에도 같은 셰이더 적용) |
| 하늘 | 하늘 셰이더 안에 6옥타브 fbm **절차적 구름**(태양 방향 자기 그림자, 가장자리 은빛 테두리, 노을·밤 색), 바람에 천천히 흐름 |
| 땅·풀 | 파쇄석·자갈·흙 텍스처 밝기로 **미세 요철 범프 노멀**, 도로는 매끈하게, 풀은 뿌리 쪽 그늘 → 끝 밝아지는 그라데이션과 역광 투과광 |
| 고양이 털 | 인스턴싱으로 몸 부위마다 9~14겹 껍질을 법선 방향으로 부풀려 그리는 **셸 텍스처링 털**: 3D 셀 해시로 털 가닥, 뿌리 쪽 자기그림자, alpha-to-coverage로 부드러운 털끝, 은빛 태비 무늬·꼬리 줄무늬를 절차적으로 생성, 역광 투과·림 라이트. 눈은 동공 크기를 조절하는 홍채 셰이더(사냥할 땐 동공이 커짐)와 반사 하이라이트 |
| 고양이 얼굴 | 머리 모양은 두개골·이마·볼·수염 패드·턱·코 등선을 부드럽게 합친 SDF(부호 거리 함수)를 구 메시에 투사해 만들고 눈구멍을 깎음. 사진에서 눈·코를 지우고 은빛으로 보정한 얼굴 텍스처를 머리 앞면에 평면 투영, 눈 주변·코·입선은 털 길이 마스크로 짧게. 눈꺼풀은 안구 셰이더 안에서 위·아래 눈꺼풀 선을 계산해 그리고, 완전히 감으면 털 덮인 눈꺼풀 패치와 ◡ 선으로 전환. 입은 정점 셰이더에서 아래턱을 내려 벌림 |
| 망원경 시야 | 화면 전체를 그리는 프래그먼트 셰이더 한 장: 배율에 맞춘 실시야로 하늘 각도를 계산하고, 날카로운 시야 조리개·주변 감광, 대기 흔들림(느린 상 흔들림 + 빠른 일렁임), 초점 흐림(픽셀마다 회전하는 16탭 원판 커널), f/10 아크로매트의 보라색 색수차 테두리를 계산. **달**은 이 망원경으로 직접 찍은 보름달 사진을 원판으로 잘라 색만 보정해 사용(밤하늘의 달은 같은 사진을 맨눈 방향으로 돌려 하늘 셰이더에 그림). **토성**은 절차적: 편평한 구(극 반지름 0.902)에 위도별 띠, 태양 방향 음영과 주연 감광, C·B·A 고리와 카시니 간극·엥케 간극, 고리면 기울기를 고려한 해석적 안티앨리어싱, 행성 그림자가 고리에 · 고리 그림자가 행성에 지는 것을 광선-평면/구 교차로 계산, 타이탄·레아·디오네·테티스와 배경 별은 시잉·초점에 따라 퍼지는 점광원. 실제 90mm에서 토성은 아주 작게 보여 화면에서는 약 10배 크게 보정 |
| 계곡 물 | 물결 높이장 정점 변위 + 픽셀 단위 해석적 법선, 깊이에 따른 투명도, 여울 흰 물살 노이즈. 보트 항적은 물 셰이더가 직접 계산: 뱃머리가 지나간 경로를 기록해 각 지점에서 나온 물마루가 시간이 지날수록 옆으로 퍼지는 켈빈 항적식 V자(앞쪽 물마루 + 안쪽 잔물결 2줄 + 바깥 골), 선미 뒤 심플렉스 노이즈 거품 띠, 선체를 감싸는 뱃머리 물결, 노 젓는 자리의 동심원 물결을 해석적 기울기로 법선에 더함 |
