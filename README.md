# 담터 별빛캠핑장 ★ 3D 둘러보기

경기 포천시 관인면 담터길 307-2 **담터 별빛캠핑장**을 캠핑장 배치도(대피안내도), 위성사진, 직접 찍은 사진·영상을 바탕으로 3D로 재구성한 웹페이지입니다. 브라우저에서 바로 실행되며 설치가 필요 없습니다.

## 기능
- 캐릭터를 움직이며 **1인칭 / 3인칭 / 항공** 시점으로 둘러보기
- **봄 / 여름 / 가을 / 겨울** 계절 전환 — 진달래·산벚과 꽃잎, 짙은 녹음과 반딧불이, 단풍과 낙엽, 눈 덮인 땅·언 계곡·눈 내림
- **낮 / 노을 / 별밤** 시간 전환 (계절별 해 높이·해 지는 시각 반영, 별밤에는 은하수와 볼라드등·줄전구·모닥불 점등)
- 캠핑장 배치도 그대로: 진입로 다리 → 멀티존·A1–A5 → 피크닉존 → B1–B15 (계곡 쪽), 별빛존 1–6·관리동/매점·화장실·샤워실·개수대·분리수거장·C1–C2·주차장·흡연구역 (산 쪽)
- 바닥 **대피로** 화살표 표시, 배치도와 같은 방향의 미니맵(클릭 이동), 바로가기, 계곡·모닥불·풀벌레·매미 소리
- **담터계곡 재현**(현장 영상 기준): 자갈 바닥이 비치는 맑고 얕은 물, 화강암 사석을 쌓은 호안, 자갈 모래톱, 돌보와 흰 물살, 물가 반영
- **여름 계곡 래프팅**: 보트를 타고 계곡을 따라 내려온 뒤, 셋이 보트를 머리 위로 들고 돌계단과 통로를 걸어 다시 올라가 띄우고 내려오기를 반복 (메뉴의 '여름 래프팅' 버튼으로 바로 이동)
- **관리동 재현**: 흰 가로 사이딩, 원형 로고가 걸린 가운데 박공동과 양쪽 경사지붕 날개동(화장실·샤워실), 유리문·통창, 벽등, 인조잔디 화단과 화분, 다듬은 소나무와 돌 화단·태양광 정원등, 줄전구, 파라솔 테이블, 홍단풍, 나무 그네 퍼걸러
- 관리동 앞 **숯불 바비큐**: 바퀴 달린 그릴(뚜껑·온도계·사이드 선반·고기·연기)과 고기를 굽고 먹는 세 사람
- **별빛존은 텐트 전용**(벨텐트·터널·티피·돔+헥사타프·에어텐트), 바로 앞 주차장은 별빛존 쪽으로 **후면주차**, 고무 휠스톱 설치
- 고급 텐트 모델: 폴 슬리브·에어빔, 메시 창과 말아 올린 스톰플랩, 원단 주름, 스커트, 가이라인·팩, 캔버스 캐빈텐트(굴뚝 포함)
- 대형 럭셔리 SUV·준대형/대형 세단·중형 SUV·미니밴·소형 SUV 급의 차량: 실제 차급 치수 기반 차체, 유리·필러·크롬 몰딩, 그릴·랩어라운드 램프, 멀티스포크 휠·브레이크, 번호판 (특정 제조사 디자인·엠블럼은 넣지 않음)
- PC(키보드·마우스)와 모바일(가상 조이스틱) 모두 지원

## 조작
| 입력 | 동작 |
|---|---|
| W A S D / 방향키 | 이동 |
| Shift | 달리기 |
| Space | 점프 |
| 마우스 드래그 | 시점 회전 (1인칭은 클릭 시 마우스 고정) |
| 휠 | 3인칭 거리 조절 |
| V | 시점 전환 |
| T | 시간 전환 |
| Y | 계절 전환 |

## 실행
GitHub Pages(Settings → Pages → Branch: `main` / `/ (root)`)를 켜면 아래 주소에서 열립니다.

https://deepsky-sh.github.io/Starligh_Camping/

로컬에서 보려면 폴더에서 `python3 -m http.server` 후 `http://localhost:8000` 을 여세요. (파일을 직접 더블클릭하면 텍스처·캐릭터가 로드되지 않습니다.)

## 구성
- `index.html` — three.js(r170, jsDelivr CDN)로 만든 전체 장면과 UI
- `tex/gravel.jpg`, `tex/forest_detail.jpg` — 현장 사진·영상에서 추출한 바닥·숲 질감
- `tex/photo*.jpg` — 시작 화면 사진
- `tex/hiker.gltf.json`, `tex/hiker_anims.json` — 캐릭터 모델(three.js 예제의 Ready Player Me 샘플 아바타)과 걷기·달리기·대기 애니메이션(three.js 예제 Xbot 애니메이션을 리타깃)

캠핑장 정보 출처: [한국관광공사 고캠핑 · 별빛캠핑장](https://www.gocamping.or.kr/bsite/camp/info/read.do?c_no=1499&viewType=read01)

배치는 배치도·위성사진·현장 사진을 바탕으로 재구성한 것으로 실제 치수와 다를 수 있습니다.
